# nomos

把一份个人操作法（本工作区 `agent-policy` 仓库里的 `AGENTS.yaml`，264 个叶子节点）用 242 条真实处境里筛出的 288 条样本做 SFT 压进一个 2B 模型的权重，并测量它到底有没有进去、代价是不是通用能力。

## 结果一行

适配器学会了写工具行（5.6% → 75.2%），动作一致率 0.0023 → 0.0968，但提升的 65.3% 是交互项、决策项独立份额只有 5.3%（区间跨 0），文字层口径不支持「决策变像了」；通用能力（配对）分两半：GSM8K **n=100**、+3.0pp、区间跨 0，没测到下降；**IFEval n=295、−12.2pp、区间 [−17.6, −6.8] 不含 0，测到下降**（184/295 → 148/295，54 掉 / 18 涨，McNemar p=2.57e-5；这个 p 是未做多重比较校正的值，而在 Bonferroni α=0.025 下它**过线**、余量约三个数量级。n=100 那一版压在两条只差 2 与 5 个词的「至少 N 词」上、翻正即 p=0.064，那条敏感性现在只属于 n=100；n=295 上把这两条、甚至 7 条字数掉点全翻正，仍然 p<0.001；要让 p 回到 0.025 门外得在 54 条掉点里翻正 19 条，而最大的单族（11 条逗号禁令）够不到这个数。掉点逐条读下来落在句式与字数两条表层轴上（就是那 11 条逗号禁令，其次 7 条字数下限），**不是「回答变短」单独能解释的**：变短在 63.7% 的题上都发生，而 54 条掉点里只有 52% 变短；词数中位数 IFEval 185 → 130；检出下限 1.7pp；n=295 不是第二次独立读数，是同一次读数把分母从 100 加到 295——前 100 条与 n=100 那轮逐字节相同，所以两版之间的一致是算术，不是印证）。同协议下带法 0.3198、不带法 0.2605，差 0.0593 [0.0263, 0.0923] 不含 0（每处境每侧 9 条），所以这把尺分得开「读了法」与「没读法」；但参照物在同一套解码下对它自己只有 0.3198 的自洽度，所以 0.0968 只能读成「离这个具体参照物多远」，不是「补上了几成法条效果」。IFEval 那一格用 Google 官方 grader（pin `e6890f85`）重算同一批 590 份输出仍是 **196/295 → 160/295、−12.2pp、[−17.6, −6.8]、55 掉 / 19 涨、p=3.38e-5**（lax −11.2pp、p=2.17e-4），所以那个负号不是我们自己那把尺子的产物；两把尺子在逐条上确实分得开（836 个指令槽里 56 个判得不一样，11 条人读读下来官方对 7 条、我们对 3 条），但换尺子只换 74 条不一致里的哪几条，没换结论。

## 一条命令

```
python3 scripts/measure_actions.py --analyse
```

在本机实测 **约 3.3 秒**（Python 3.12，纯 CPU、不碰 GPU、不联网、只用标准库；同一命令在一个全新 `git clone` 里同为约 3.3 秒）。计时条件与两次读数记在 [`docs/plan/plan.md`](docs/plan/plan.md) 的「发布准备」。它从仓库里已提交的证据重算主指标，并打印第一行：

```
n_pairs 148/242（覆盖率 0.612）；两侧都齐全 242/242；参照物可用 148 条；文字层参照物可用 169 条
```

后面跟完整的 `summary.json`（`base_mean` 0.0023、`post_mean` 0.0968、Δ 与按处境配对自举的区间、三个口径与格式/决策分解）。它会把 `evidence/measure/summary.json` 重写一遍：在本仓库里逐字节相同（跑完 `git status` 干净），唯一会变的字段是 `models.*` 的绝对路径，所以从别处 clone 出来跑会看到那里的路径。

需要重训或重新生成会要 GPU：`python3 scripts/train_sft.py --epochs 3 --lora-r 16 --lora-alpha 32 --lora-targets narrow`（单卡 4090 约 14 分钟），`python3 scripts/measure_actions.py --generate`（两个模型各 3 条抽样）。复现的完整说明在各报告里，见下。

## 不是什么

- 不是通用对齐研究，不涉及前沿模型：只有 2B、一个用户、一份法。
- 不是人类偏好标注的 RLHF：偏好对由政策推导。
- 不是「这份法比别的法好」：它是一名用户的操作法，测的是「更接近它」，不是「更正确」。
- 不是 benchmark 论文：外部套件只回答「有没有掉」，GSM8K n=100（检出下限 4–5pp）、IFEval n=295（检出下限 1.4–1.7pp），且只有这两条轴，agentic 那一条未测。

## 限制

- 单一用户、单一份法、单一模型尺寸（2.21 B）；法变了，本适配器不自动成立。
- 288 条训练样本、242 条处境，151 条处境只有一种决策；覆盖 175 条可训练规则里的 77 条（下界）。
- 窄版 LoRA 只挂 `q/k/v/o`（6 层全注意力）与 MLP（24 层），18 层线性注意力的投影没挂——宽版重跑更差，所以这是选择不是缺口。
- 一致率只在 148/242 条处境上算（94 条参照物定不下来），不能外推全域；一致率是「像不像带法 DeepSeek」，不是正确率。
- IFEval 那一格与公开数值不可比：抽样是 541 条里的 295 条，而且同一批输出的分数取决用哪把尺子——官方 strict 是 66.4% → 54.2%，本仓库那把是 62.4% → 50.2%，差值的区间两边一样。官方 grader 不钉 `langdetect` 种子时自己也不可复现（±1 条）。
- 尺子量的是「离参照物多远」而不是「补上了几成法」：同协议下带法 0.3198、不带法 0.2605，差 0.0593 [0.0263, 0.0923] 不含 0（每处境每侧 9 条）；3 条时同一条差是 0.0496 [−0.0068, 0.1059]、跨 0，那份宽度是抽样噪声（区间宽按 1/√3 收缩）。参照物自身只有 0.32 的自洽度，文字层口径二仍跨 0（0.0303 [−0.0180, 0.0819]）。
- 权重不在 git 里（`.tmp/` 是可删临时区），只有 sha256 与重生成命令登记在 [`artifacts.tsv`](artifacts.tsv)。
- 完整清单：[`docs/method/limits.md`](docs/method/limits.md)、[模型卡](docs/model-card.md) 的「已知限制」。
