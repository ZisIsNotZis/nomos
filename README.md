# nomos

把一个人写的操作法（`AGENTS.yaml`，264 个叶子节点，计数由 [constitution/nodes.json](constitution/nodes.json) 生成）压进一个 ≤2B 模型的权重里，并测量它是否真的进去了、代价是不是通用能力。

## 它是什么

一份实验规格、一套数据与评测管线、以及最后能不能支撑一句话的相对主张：

> 在没有法条原文的上下文里，微调后的 Qwen3.5-2B 在"该动还是不该动"的判断上更接近"带法 DeepSeek"的水平，而通用与 agentic 能力不跌出自身噪声带。

主张的形状是"补上了多少差距"，不是"达到多少分"。负结果同样是结果。

## 它不是什么

- 不是通用对齐研究，不涉及任何前沿模型。
- 不是人类偏好标注的 RLHF：偏好对由政策推导，不由人打分。
- 不是"我们的法比别的法好"：这是一份个人操作法，不是普适规范。见 [limits](docs/method/limits.md)。
- 不是 benchmark 论文：外部套件只用来证明"没变差"和"能在陌生法上迁移"。

## 现状

规格与预注册已写；尚无数据、无训练、无可运行评测。

- [实验规格](docs/method/spec.md)：主体、参照、数据契约、评分、门
- [预注册](docs/method/prereg.md)：跑任何评测之前锁死的阈值与停止规则
- [边界与不能主张的东西](docs/method/limits.md)
- [M1 计划](docs/plan/m1.md)：工作包、验收、预算
