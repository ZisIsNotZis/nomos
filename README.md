# nomos

把一份个人操作法（`/home/z/vibe/AGENTS.yaml`）压进一个 2B 模型的权重，并测量它到底有没有进去、代价是不是通用能力。

## 现状

数据已就位：183 条真实处境，各有一条"带法"和一条"不带法"的 DeepSeek 回答，落 `data/pairs.jsonl`。下一步是数据质量与覆盖计数，然后训练。

- [设计](docs/method/design.md)：主张、刻度、数据、rubric、噪声、停止规则
- [计划](docs/plan/plan.md)：七步与每步验收
- [测量结果](report/measurements.md)：现有数字与证据指针
- [边界](docs/method/limits.md)：法不覆盖什么、本研究不能声称什么
- [冲突审计](docs/method/conflicts.md)：68 对，真冲突 0
- [法的冻结件](constitution/)：264 个叶子，可训练 175

## 不是什么

- 不是通用对齐研究，不涉及前沿模型。
- 不是人类偏好标注的 RLHF：偏好对由政策推导。
- 不是"这份法比别的法好"：它是一名用户的操作法。
- 不是 benchmark 论文：外部套件只回答"有没有掉"。
