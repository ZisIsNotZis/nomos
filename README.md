# nomos

把一份个人操作法（本工作区 `agent-policy` 仓库里的 `AGENTS.yaml`）压进一个 2B 模型的权重，并测量它到底有没有进去、代价是不是通用能力。

## 现状

数据已就位：183 条真实处境，各有一条"带法"和一条"不带法"的 DeepSeek 回答，筛掉两侧同动作与坏件后 174 条入账，每条标了 1–4 条可训练规则。评委尺子已做出来并测过分辨力：在 64 组已知水平上分不开两侧（合成分差 −0.001，区间 [−0.0265, 0.0255]），所以训练还没开始。

- [设计](docs/method/design.md)：主张、刻度、数据、rubric、噪声、停止规则
- [计划](docs/plan/plan.md)：七步与每步验收
- [测量结果](report/measurements.md)：现有数字与证据指针
- [数据质量](report/data-quality.md)：筛除判据、逐条丢弃、覆盖分布与不足
- [rubric 与分辨力](report/rubric.md)：四维判据、评委协议、分不开的结论与噪声
- [稳定对子集](report/stable-pairs.md)：两侧可复现的对、它上面的跨条件差与判读复测
- [增长批次](report/grow-pairs.md)：59 条未用处境补跑四次抽样，新增 25 条稳定对，合并 v2 91 条；零覆盖规则 98 → 91
- [边界](docs/method/limits.md)：法不覆盖什么、本研究不能声称什么
- [冲突审计](docs/method/conflicts.md)：68 对，真冲突 0
- [法的冻结件](constitution/)：264 个叶子，可训练 175

## 不是什么

- 不是通用对齐研究，不涉及前沿模型。
- 不是人类偏好标注的 RLHF：偏好对由政策推导。
- 不是"这份法比别的法好"：它是一名用户的操作法。
- 不是 benchmark 论文：外部套件只回答"有没有掉"。
