## CONFIRMED

### 主张（发布文本里唯一被允许的说法）

> 一个 2B 模型能在**没有法条原文的上下文**里，做出接近「带法 DeepSeek」的下一步判断，
> 同时**通用能力**不跌出自身噪声带——两条实测轴是 GSM8K（推理，n=100）与 IFEval（指令合规，n=295）。

**agentic 能力不在这条主张里**：本轮一个候选套件也没跑，四个各被一个具名的缺失依赖挡住
（选型表与逐条原因在 `evidence/reports/sft-benchmark.md`「选型」）。所以本研究不声称它没跌，也不把它当已测来讲。
这条主张由 `scripts/check_axes_claim.py` 守着：提到 `agentic` 的每一句必须同句写明没测，两处主张段必须点名 GSM8K 与 IFEval。

### 不是什么

- 不是通用对齐研究，不涉及前沿模型：只有 2B、一个用户、一份法。
- 不是人类偏好标注的 RLHF：偏好对由政策推导。
- 不是「这份法比别的法好」：测的是「更接近它」，不是「更正确」。
- 不是 benchmark 论文：外部套件只回答「有没有掉」，且只有两条轴。

### 边界：这份法不覆盖什么

以下是主代理对 `AGENTS.yaml` 的读法（推断，非作者确认）：它是一份**单人对单代理协作**的操作法，
其覆盖范围由它的角色定义决定。它没有、也不打算覆盖：

- **多用户与权限体系**：没有租户、角色、审计追责，只有「用户」与「代理」。
- **对抗性使用**：它约束一个受信任的协作者，不是防恶意护栏；压进权重不会让模型变得不可滥用。
- **多模态输入**：`multimodal_review` 提到人工多模态复核，但法不定义图像、音频、视频的处理义务。
- **法律、合规、监管**：`secrets` 覆盖密钥泄露，不覆盖个人数据、隐私法规、跨境传输。
- **长期多项目治理**：只有里程碑与同步点，没有多团队、多季度、多人接力的治理模型。
- **物理世界与真实资金**：只说高额花费需同意，没有预算、账务、诈骗、金融合规。
- **训练与评测研究本身**：它要求证据与可复现，但不规定实验伦理、数据来源同意、模型发布的边界。
  本研究对法的适用因此是**推断**，不是法条授权。
- **模型能力的下限**：法假定执行者「有能力但会漂移」，没有回答「能力不足以执行时怎么办」——这正是 2B 上撞到的墙。

### 边界：本研究不能声称什么

- 不能超出被测尺寸（2B；可选 0.8B），不外推到 7B、前沿模型或别的架构。
- 不能声称「更接近这份法」在普适意义上更好。
- 不能声称与人判一致：评分来自 rubric，评委是模型；人只在模型分歧处裁决。
- 不能声称参照物是法：`X = 100` 只意味着「和它一样」。
- 不能声称纯权重内化已排除读文档：训练与评测都不放法条原文是必要条件，不是充分条件。
- 不能声称覆盖全部规则：覆盖率的分母是进入训练的规则数（175），不是叶子总数（264）。
- 不能声称稳健：所有结论带区间，区间之外无言。
- 不能声称外部套件的绝对分与公开数值可比：换一把尺子就换绝对分（官方 strict 66.4% → 54.2%，
  本仓库 62.4% → 50.2%），差值区间两边相同；抽样是 541 条里的 295 条。
- 不能声称 agentic 能力没跌（未测）。
- 不能声称留出处境上与见过处境一样强：见过侧 Δ +0.1091、留出侧 +0.0476（35 条，只读方向）。
- 不能声称长期有效：结论绑定一个法的哈希。

## INFERRED

### 判定树（每条带理由、代价与被什么推翻）

**1. 口径二（第二把尺子）不开。**（2026-10-23，本节点按下放的 ¥10 判定权）
理由：要让论文那句变，得让 99 条上的 0.0303 [−0.0180, 0.0819] 排除 0。按 9 条抽样的 SE 外推，
25 / 35 / 50 条每侧时下界是 +0.0003 / +0.0050 / +0.0091，追加 4736 / 7696 / 12136 次调用、
约 ¥3.8 / ¥6.2 / ¥9.7——**钱不是拦路那条**。拦路的是投影本身不成立：同一样本从 3 条加到 9 条时
点估计从 −0.0101 翻成 +0.0303，符号在抽样数之间本来就不稳。真正治它的是参照物的分辨力
（64.5% 单一特征签名、82/169 只剩 `artifacts`），那是口径变更，不在 ¥10 之内。
**推翻条件**：同样 99 条上多抽一批而点估计稳在 0.03 附近（不翻符号），或换一个能分辨的参照物后
99 条上给出不含 0 的区间。任一条出现就重开；代价仍 ≤¥10 本节点自己开，>¥10 回 root。

**2. `agentic` 窄化，不买这条轴——这条轴本轮未测，不进主张。**（2026-10-23，M5）
理由：BFCL 要 HF 可达 + 上千行判分 harness，两个依赖在本机都不成立（选型表逐条写），代价远超 ¥10；
而发布文本把没量过的轴当已测讲，比不说更坏。
**推翻条件**：有人在本机解掉 BFCL（或等价套件）的离线与判分依赖，那时代价重算，主张可以重新加回去。

**3. 数字可以按原措辞冻，§4.7 的因果句不能冻。**（上一层 2026-10-21 回信，已落地）
冻结带条件：IFEval 的 −12.2pp 在 n=295 上区间不含 0、p 过 Bonferroni；GSM8K 只能写「没测到下降」。
机制句从「回答变短」降级为「背景位移，不是判别式」：54 条掉点里只有 52% 变短，而两侧都对的 130 条里
68% 更短，变短选不出掉点。

**4. 参考实现复核不触发「跨 0 就停」那条闸。**（M4）
官方 strict 与 lax 的区间都不含 0，所以 −12.2pp 不是自己那把尺子的产物；剩下面临的攻击只剩口径选择
（同一条 seed-0 贪心路径、格式类指令占比、官方 strict 的 Wilson 上沿 71.6% 比判别带上沿高 1.6pp）。

**5. 尺度必须自建、且先证明有刻度。**（M1）
同协议下带法 0.3198、不带法 0.2605，差 0.0593 [0.0263, 0.0923] 不含 0；3 条时同一条差
0.0496 [−0.0068, 0.1059] 跨 0，那份宽度是抽样噪声（按 1/√3 收缩）。没有这一步，政策轴的任何数都只是噪声。

**6. 见过 / 留出必须拆开读。**（WP-6）
242 条测量处境全部是造训练数据的同一批：113 条配对在训练集、35 条按会话留出。
头行 0.0968 是加权平均，113/148 来自见过的处境，读不出「内联进去了」与「背下来了」的区别。
