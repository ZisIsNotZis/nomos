# 边界

类型：方法。所有者：主代理。上游：[设计](design.md)。

这份文件有两半：法本身不覆盖什么，以及本研究不能声称什么。两半都要进论文，且都不是免责声明而是结果的一部分。

## 1 这份法不覆盖什么

以下是主代理对 `AGENTS.yaml` 的读法（推断，非作者确认）：它是一份**单人对单代理协作**的操作法，其覆盖范围由它的角色定义决定。

它没有、也不打算覆盖：

- **多用户与权限体系**：没有租户、角色、审计追责的概念，只有"用户"与"代理"。
- **对抗性使用**：它约束一个受信任的协作者，不是防恶意的护栏。把法条压进权重不会让模型变得不可滥用。
- **多模态输入**：`multimodal_review` 提到人工多模态复核，但法本身不定义图像、音频、视频的处理义务。
- **法律、合规、监管**：`secrets` 覆盖密钥泄露，但不覆盖个人数据、隐私法规、跨境传输。
- **长期多项目治理**：只有里程碑与同步点，没有多团队、多季度、多人接力的治理模型。
- **物理世界与真实资金**：只说高额花费需同意，没有预算、账务、诈骗、金融合规。
- **训练与评测研究本身**：它要求证据与可复现，但不规定实验伦理、数据来源同意、模型发布的边界。本研究对法的适用因此是**推断**，不是法条授权。
- **模型能力的下限**：法假定执行者"有能力但会漂移"。它没有回答"能力不足以执行时怎么办"，这正是本研究在 2B 上撞到的墙。

## 2 本研究不能声称什么

- **不能超出被测尺寸**：只报 2B（可选 0.8B）。没有任何依据外推到 7B、前沿模型或别的架构。
- **不能声称"更接近这份法"在普适意义上是更好**：这是一个人的操作法。它在某些场景下可能比默认行为差；本研究测的是"是否更接近这份法"，不是"是否更接近正确"。
- **不能声称与人判一致**：评分来自 rubric，rubric 由主代理从法条推出，评委是模型。人（法条作者）只在模型之间分歧处裁决，覆盖面有限。
- **不能声称参照物是法**：DeepSeek 带法的回答是参照物，不是判据。`X = 100` 意味着"和它一样"，不意味着"对"。
- **不能声称纯权重内化已排除读文档**：训练与评测的上下文都不放法条原文，这是必要条件；但 τ-bench 的政策在上下文里，那部分证据只支持"带着陌生法更能守"。
- **不能声称覆盖全部规则**：工具与宿主绑定的节点被显式排除；conceptual 与 definitional 节点不进样本主体。覆盖率的分母是进入训练的规则数，不是叶子节点总数（264，见 [constitution/nodes.json](../../constitution/nodes.json)）。
- **不能声称稳健**：数据来自一个人的真实会话与合成切片，样本量与场景分布都受限；所有结论都带区间，且区间之外无言。
- **不能声称外部套件的绝对分与公开数值可比**：同一批落盘输出换一把尺子就换绝对分——IFEval 官方 strict grader 给 66.4% → 54.2%，本仓库自己的检查器给 62.4% → 50.2%，差值区间两边相同。与公开 IFEval 数比只能用官方那一行，而且抽样是 541 条里的 295 条；参考实现本身不钉 `langdetect` 种子时也不可复现（±1 条）。详见 [`report/sft-benchmark.md`](../../report/sft-benchmark.md)「参考实现的尺子」。
- **不能声称 agentic 能力没跌**：这条轴本轮没有测量——最接近它的候选（BFCL 多轮）卡在离线不可达与判分 harness 成本上（选型表与逐条原因见 [`report/sft-benchmark.md`](../../report/sft-benchmark.md)「选型」）。对外只声称实测过的两条轴（GSM8K、IFEval）；「没有好几处退化」这句话在本研究里只覆盖这两条轴。
- **不能声称留出的处境上与见过的处境一样强**：242 条测量处境全部是造训练数据的同一批处境，其中 51 条按会话留出。见过侧 113 条配对 Δ +0.1091 [0.0678, 0.1593]、留出侧 35 条配对 Δ +0.0476 [0.0095, 0.0857]——留出侧的「写工具行」（可解析动作 6.7% → 80.0%）成立，签名命中只有见过侧的四成多，且 35 条上只能读方向。所以「权重里内联了这套法」这句话，在留出处境上最多说到「朝法走了半步」。详见 [`report/sft-measurement.md`](../../report/sft-measurement.md)「见过 / 留出」。
- **不能声称长期有效**：法在演进，本研究绑定一个版本的哈希。法变了，结论对新版本不自动成立。
