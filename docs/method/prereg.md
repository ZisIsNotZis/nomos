## 1 主张与判定规则

记 `X_d` 为维度 d 的归一化分数，`X_d = (qwen_d − base_d) / (deepseek_d − base_d)`，各自带 95% 区间。

| 观察 | 判定 | 产出 |
|---|---|---|
| 至少 3 个维度 `X_d` 的区间下界 > 0，且没有任何通用维度跌破 §4 的损伤线 | 内化成立 | preprint，报"补上了多少差距" |
| `X_d` 的区间包含 0 或整体接近 0 | 负结果 | 照常发布：该尺寸装不下这套法 |
| 某维 `X_d` 区间下界 > 100 | 超过参照物 | 先复现再声称；这条最有价值也最脆 |
| 至少一个维度的 `X_d` 区间下界 > 0，但相位与授权维度的区间含 0 或整体小于 0 | 只学到表层，没学到裁决 | 不改结论，报维度剖面 |

禁止的形状：把一个维度当全局结论；把总分当精度；把 loss 下降当证据；把饱和仪器量出的零当成"无效应"。

## 2 样本与次数

- **停止规则**：每档最少 3 次；若某维区间半宽 > δ 则加到 5 次；上限 5 次，主表上限 8 次。
- `δ = 5` 个百分点（该维度原始量表上的点），预注册值，未校准。
- **评测重复**：每档 3 次起，解码温度 0（或固定 seed）。
- **训练重复**：只对主表数字做 2–3 个训练 seed，报极差。探索性实验一律单 seed。
- **场景数**：先导批 40–100 条处境；总量 `N` 留空，由先导批的方差与 §3 的评委预算共同决定，填在此处后锁死。
  先导批方差实测值：未知。总量：未知。
- 评委判读次数：每条轨迹 3 次；另抽 20% 由第二个模型家族再判 1 次，报一致率。

## 3 评委协议

- 评委不知道轨迹来自哪个模型。
- 打分项与权重见规格 §3.1；每个维度先报分量，再报总分，总分注明可靠性。
- 评委输出必须是结构化字段（二值项、计数项），散文只作发现未建模失败类的材料。
- 评委与"带法生成者"必须不同源。
- 评委成本按实测单价 × 判读次数记账，超预算则**减少场景数**，不减少每场景的判读次数。

## 4 通用能力的损伤线

对每个通用套件，`Δ` 相对自身噪声：`σ = max(训练 seed 间极差, 评测重复间极差)`。

- `|Δ| ≤ 2σ`：在噪声内，报"未观察到下降"。
- `Δ < −2σ`：报"下降"，并分套件看形状——知识套件不动而指令跟随套件掉，指向程序化过度谨慎；两个都掉，指向通用能力受损。两种病因分开报。
- 套件必须先实测落在 30–70% 的 headroom 内，贴地板贴天花板一律换掉，并记录换的理由。
