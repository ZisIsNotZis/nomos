# 目标

## EXPLICIT

- 验收线原话：「没有好几处性能退化」。怎么判在 person 手里；本节点不改这条线。
- 可回 root 的三件：>¥10 的花费、改变这条验收线怎么判、要 person 亲自看的产物。

## CONFIRMED

- 主张只覆盖**实测的两条通用能力轴**：GSM8K（推理）与 IFEval（指令合规）。agentic 轴明确不在主张里
  （2026-10-23 按下放的判定权决定窄化，见 [`5_PRODUCT.md`](5_PRODUCT.md)）。
- 外部套件只回答「有没有掉」，不回答「多强」：绝对分与公开数值不可比（抽样是 IFEval 541 条里的 295 条）。
- 判别带：一条通用能力轴只有在 base 落在 30–70% 才有判别力；贴地板或贴天花板一律换掉。
- 「一个变化只有在大于自身噪声时才算变化」：每个数带区间，区间盖住差异时写「分不开」，不写方向。

### 范围与非目标

- 范围：2B 级（实测 2.21 B）、一个用户、一份法、一次 SFT。
- 非目标：通用对齐研究、RLHF、证明「这份法比别的法好」、benchmark 论文、agentic 能力研究。
- 优先顺序（本节点的取舍）：证据质量 > 结论宽度 > 花费 > 速度；能并行就并行，但一次只改一个变量。
