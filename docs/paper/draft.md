# 把一份个人操作法压进 2B 权重：SFT 学到的是格式，不是决策

草稿。类型：论文。所有者：主代理。上游：[设计](../method/design.md)、[边界](../method/limits.md)。

所有数字取自 `report/`，本文不重算、不推导新数。文末「数字出处」逐条给出承载它的报告。

## 摘要

我们问一个具体的问题：把一个人写给 AI 代理的操作法（264 个叶子节点）压进一个 2B 模型的权重，会让它在**上下文里没有法条原文**的处境下做出更接近「读了法」的下一步判断吗？

在一台 4090 上对一个 2B 基座做 4-bit QLoRA（288 条训练样本、3 个 epoch），然后在这条法、这个模型、这套解码下测三件事：模型是否开始写可解析的工具行、写了之后动作是否更像带法强模型、通用能力有没有掉。

答案分成两半，而且更重要的那一半是否定的。适配器把**可解析工具行的产出率从 5.6% 提到 75.2%**，动作签名一致率从 0.0023 升到 0.0968（Δ = 0.0946，95% 区间 [0.0586, 0.1351]，n_pairs = 148）。但把这次提升拆开：以训练前基座为起点，格式项占 29.4%、决策项独立份额只有 5.3%（区间 [−0.0001, 0.0099]，跨 0）、交互项占 65.3%；不依赖评委的文字层口径**不支持**「决策变像了」（Δ = −0.0473，[−0.1085, 0.0118]）。通用能力一侧，两个 benchmark 各 n=100、同一条冻结样本前缀、配对比较：GSM8K **+3.0pp**，区间 [−6.0, +12.0] 跨 0；**IFEval −12.0pp，区间 [−22.0, −3.0] 不含 0**（19 掉 / 7 涨，McNemar p = 0.029）。所以这一侧不能再写成「没有可信的下降证据」：格式合规上测到一个 12 点的代价，推理上没有测到下降（这个 n 的检出下限是 4–5pp，也就是 4–5pp 以上的掉幅会被看见）。

还有一个必须先说的结论：**这把尺子能量出法的作用，但量的是「离参照物多远」，不是「补上了几成法」**。在同一套解码下、同一批 148 条处境上，每侧每处境抽 9 条，带法侧对它自己的多数签名是 0.3198 [0.2703, 0.3746]，不带法侧 0.2605 [0.2072, 0.3116]，差 0.0593 [0.0263, 0.0923]，**区间不含 0**。3 条抽样时同一条差是 0.0496 [−0.0068, 0.1059]、跨 0：点估计只动了 0.0097，而区间宽从 0.1127 收到 0.0661（比值 0.587，与 1/√3 = 0.577 一致），所以原来跨 0 的那一份是抽样噪声，不是法没有作用。参照物本身在同协议下只有 0.32 的自洽度，所以这个差读作「适配器离一个具体参照物多远」的刻度，不读作法条效果被补上了几成；文字层的口径二在同批 99 条上仍然跨 0（0.0303 [−0.0180, 0.0819]）。

## 1 主张与刻度

主张（[设计](../method/design.md) §1）：一个 2B 模型能在没有法条原文的上下文里做出接近「带法 DeepSeek」的下一步判断，同时通用与 agentic 能力不跌出自身噪声带。前半句是本文测的。后半句现在要分两截写，而且两截的状态不同：**通用能力一侧已经测到 n=100**（§4.7）——GSM8K 未测到下降（+3.0pp，区间 [−6.0, +12.0] 跨 0），**IFEval 测到 −12.0pp（区间 [−22.0, −3.0] 不含 0）**，所以「通用能力不跌出自身噪声带」在一格上被自己的数据否掉、在另一格上未被推翻；**agentic 一侧本轮仍然没有测**：四个候选套件各被一个具名的缺失依赖挡住（离线不可得、缺 `pyarrow`、判分 harness 成本），选型表与逐条原因在 [`report/sft-benchmark.md`](../../report/sft-benchmark.md)「选型」。所以那半句话里「agentic 不跌」这一截仍不可证伪，不是被验证过；「通用不跌」这一截已经不是不可证伪的了，它有一格反例。

刻度原设计是 `X_d = (qwen_d − base_d) / (deepseek_d − base_d)`，逐维度算。本研究中段发现两件事，刻度因此被改写而不是被引用：

1. rubric 在 64 组已知水平（带法 vs 不带法）上分不开两侧：合成分差 −0.001，区间 [−0.0265, 0.0255]（[`report/measurements.md`](../../report/measurements.md)）。评委仪器没有分辨力，所以主指标换成**不依赖评委的、可数的动作签名一致率**，rubric 只作辅助照报不照判。
2. `deepseek` 这一端在同协议下也不自洽（§5.6），所以 X 的分母虽然定义清楚，语义是空的。

X 照算并报出：X = 0.0948 [0.0564, 0.1332]。但 base 侧口径一只有 0.0023，分母 `1 − base = 0.9977`，**X 实际就是 post_mean 本身**，它在这份数据上没有独立含义（[`report/sft-measurement.md`](../../report/sft-measurement.md)「X」一节）。

## 2 方法

### 2.1 处境与 prompt

单位是**处境**：一段真实会话的最小片段，含工具面清单与一个决策点，以用户轮结尾。prompt = 处境原文 + 一句续写指令，**不含任何法条原文**；构建时用 175 条法条短语逐条查，命中即停，并有两条负控证明断言会响（[`report/sft-data.md`](../../report/sft-data.md)）。

### 2.2 训练

| | 值 |
| --- | --- |
| 基座 | `Qwen/Qwen3.5-2B`，revision `15852e8c…`，22.1 亿参数，Apache-2.0 |
| 量化 | 4-bit nf4 + double quant + bf16 compute（QLoRA） |
| LoRA | r=16、alpha=32、`narrow` 目标（`q/k/v/o` × 6 层全注意力 + `gate/up/down` × 24 层），10 911 744 个可训练参数（0.79%） |
| 数据 | 288 条训练 / 78 条验证，3 epoch = 54 步，有效 batch 16，seed 0，lr 1e-4 |
| 耗时 | 828.6 秒（单卡 4090，与另一个项目共用） |
| 损失口径 | 只对 target 算 loss，prompt 与 pad 位置全部 −100，运行时逐条断言 |

宽版对照（LoRA 也覆盖 18 层线性注意力的 5 个投影）验证 PPL 6.0923 差于窄版 6.0325 且第三轮反弹，所以后续测量用窄版（[`report/sft-training-wide.md`](../../report/sft-training-wide.md)）。

### 2.3 测量协议

**两套解码，不能混用**（[`report/sft-measurement.md`](../../report/sft-measurement.md)「两套解码」）：

| 批次 | 温度 / top_p / max tokens | 抽样 |
| --- | --- | --- |
| base、post、匹配锚点 | 0.7 / 0.95 / 320 | 本机两侧各 3 条；匹配锚点每侧 9 条 |
| 参照物与旧刻度 | 0.0 / 默认 / 600 | 3.04 条 |

同协议可相减的只有：base 对 post、匹配锚点内部带法对不带法、旧批次内部带法对不带法。跨协议相减过一次并被纠正：旧的 bare 刻度 0.3502 对同协议的 0.2605 之差 0.0897 [0.0458, 0.1385] 全部来自解码（3 条时的同协议刻度是 0.2815、差 0.0687 [0.0146, 0.1239]；见 [`report/sft-measurement.md`](../../report/sft-measurement.md)「修掉的问题」第 9 条）。

三个并列口径与一个分解：

1. **动作签名一致率（主指标）**：`tool: name(args)` 压成有序签名元组，与「带法 DeepSeek 的多数签名」全等才算命中。
2. **文字层决策签名一致率**：把回答压成「提问/停住/断言/产物」四位，不依赖工具语法。它的弱点是参照物里 64.5% 是单一特征签名（其中 82/169 只剩「产物」）。
3. **动作可比子集一致率**：只在该侧已有可解析动作的处境上算。
4. **格式/决策分解**：`mean = P × A`，Δ 用两种约定（Kitagawa 中点；以 base 为起点并把交互项单列），两种都精确闭合。

参照物只在「带法侧至少 2 条抽样给出同一签名」且「该签名非空」时可用；两者之一不成立就不计入任何分子分母，并单独计数。区间一律按**处境**配对自举，2000 次重抽。

## 3 数据

242 条处境、51 个会话（47 个会话组），来自法条作者本人的 agent 会话档案：3312 个 JSONL、275 个交互会话、1746 条用户轮、86 273 次工具调用，结构信号命中 455 个候选窗口（[`report/measurements.md`](../../report/measurements.md)）。

双答与加密抽样的生成方式是同一处境问两次以上：`law` 条件在 system 消息里放整部法，`bare` 条件不放；模型 `deepseek-flash`，温度 0.0、600 token、thinking 关闭。加密批次 242 处境 × 2 条件 × 3.04 次 = 1470 次调用、¥1.253，其中 `law` 的 735 条是 SFT 候选 target。

735 条 → **366 条样本**（训练 288 / 验证 78），丢弃 369 条：截断 3、逐字重复 94、同动作签名 244、同文字层决策且词集 Jaccard ≥ 0.5 共 28、近重复 0。切分按会话组（10 组、78 条、21.3%），同组同处境都不跨两侧，种子 20261020（[`report/sft-data.md`](../../report/sft-data.md)）。覆盖 175 条可训练规则中的 77 条，且 77 是下界（68 条处境没有规则标注）。

脱敏：绝对路径、URL、邮箱、各家令牌、`key: value` 凭据、长十六进制/base64 串在写入前替换；含私钥块或高置信凭据的窗口整条丢弃（本轮真丢 3 条）；原始会话不进仓库（[`docs/data-card.md`](../data-card.md)、`mining/check_redaction.py`）。

## 4 结果

### 4.1 训练跑通并学到东西（不证明学会法）

验证 PPL 11.34 → 6.03（loss 2.4285 → 1.7972），训练 PPL 4.21，训练/验证 loss 差从 0.1057 涨到 0.3596，第三个 epoch 验证侧只降 0.037。结论写到「学到了数据里的回答形态，没有过拟合到掉头的程度，也没有证明学会了法」（[`report/sft-training.md`](../../report/sft-training.md)）。

### 4.2 主指标：一致率提升方向是稳的

n_pairs = 148/242（覆盖率 0.612；94 条处境的参照物定不下来，54 条空、40 条没有多数）。

| 水平 | 解码 | 一致率 | 区间 |
| --- | --- | --- | --- |
| base（训练前基座） | 0.7/0.95/320 | 0.0023 | [0.0000, 0.0068] |
| post（窄版适配器） | 0.7/0.95/320 | 0.0968 | [0.0586, 0.1374] |
| 不带法 DeepSeek（同协议，9 条） | 0.7/0.95/320 | 0.2605 | [0.2072, 0.3116] |
| 带法 DeepSeek（同协议，9 条） | 0.7/0.95/320 | 0.3198 | [0.2703, 0.3746] |
| 带法 DeepSeek（参照物本身） | 0.0/—/600 | 1.000 | 定义上，不是测量 |

base 侧是 444 条回答里 1 条命中，区间下界贴 0 是离散结果，不是真值 0。

### 4.3 提升的构成：格式与交互项

| 量 | base | post |
| --- | --- | --- |
| P（回答里有可解析动作） | 0.0563（25/444） | 0.7523（334/444） |
| A（有动作的回答里吻合） | 0.0400（1/25） | 0.1287（43/334） |
| P × A | 0.0023 | 0.0968 |

Δ = 0.0946 [0.0586, 0.1351]。两种等价拆法：

| 约定 | 格式项 | 决策项 | 交互项 |
| --- | --- | --- | --- |
| 中点（Kitagawa） | 0.0587（62.1%，[0.0294, 0.1041]） | 0.0359（37.9%，[−0.0007, 0.0658]） | 平分成两半 |
| 以 base 为起点 | 0.0278（29.4%，[0.0000, 0.0985]） | 0.0050（**5.3%**，[−0.0001, 0.0099]） | 0.0618（**65.3%**，[−0.0013, 0.1137]） |

两种拆法残差都在 1e−15 内。所以「格式占几分」没有与约定无关的答案：只报 62/38 会把「主要是学会写工具行」说得比数据能支持的更确定。能确定的是 P 的 5.6% → 75.2%（不依赖参照物）；A 方向为正但份额从 5.3% 摇到 37.9%，区间下界都贴 0，**不能断言「写了动作之后选得更对」**。

### 4.4 文字层口径：不支持改善

n_pairs = 169。base 0.3412 [0.2840, 0.3984]、post 0.2939 [0.2406, 0.3471]，配对 Δ = **−0.0473**，区间 **[−0.1085, 0.0118]**。区间跨 0，能排除的是「改善超过 1.2 个百分点」与「变差超过 10.9 个百分点」；不能排除的是这之间的一切，包括点估计。读作「不支持改善」，不读作「否掉了改善」。

### 4.5 口径三：样本不足，只作方向

动作可比子集：base 侧 23 条处境 0.0145、post 侧 137 条 0.1046 [0.0657, 0.1484]、两侧配对 22 条 Δ = +0.1061 [0.0303, 0.1818]。22 < 30 条阈值，按规则不作结论。这条口径没有不带法 DeepSeek 的读数，是缺的值，不拿别的数顶替。

### 4.6 尺子能量出法，但量的是「离参照物多远」

匹配锚点（同协议、prompt 逐条 sha256 同字节；原批 888 次调用 ¥0.7115，2026-10-21 追加 1 776 次 ¥1.4184 把每处境每侧抽到 9 条，两批合计 2 664 次 ¥2.1300）给出的是这条对照：

- 口径一（148 条处境）：带法 0.3198 [0.2703, 0.3746]、不带法 0.2605 [0.2072, 0.3116]，差 0.0593 [0.0263, 0.0923]，**不含 0**。
- 口径二（99 条相交子集）：带法 0.5735 [0.5185, 0.6296]、不带法 0.5432 [0.4770, 0.6061]，差 0.0303 [−0.0180, 0.0819]，跨 0。

3 条抽样时口径一是 0.0496 [−0.0068, 0.1059]、口径二是 −0.0101 [−0.0842, 0.0640]，两个都跨 0。同一批处境、同一套解码，只把每侧抽样从 3 条加到 9 条，点估计动了 0.0097，区间宽从 0.1127 收到 0.0661（比值 0.587，与噪声按 1/√3 = 0.577 收缩一致）：原来跨 0 的那一份是抽样噪声，不是法没有作用。参照物 1.000 是定义而非测量；同协议下可测的带法侧是 0.3198——带法 DeepSeek 在温度 0.7 下对自己的 0.0 多数签名只有 32% 的复现率。所以 X 与「对不带法刻度的差」能读成一个位置，但只能读成**离这个具体参照物多远**，不是「补上了几成法条效果」：尺子分得开两端，只是两端都低，差值量级约 6 个百分点。

### 4.7 通用能力：IFEval 测到 −12pp，GSM8K 未测到下降

| 套件 | base | adapter | 差值 | 配对 95% 区间 | 翻转（掉/涨） | McNemar p |
| --- | --- | --- | --- | --- | --- | --- |
| GSM8K | 73/100 = 73.0% | 76/100 = 76.0% | +3.0pp | [−6.0, +12.0] | 10 / 13 | 0.678 |
| IFEval | 57/100 = 57.0% | 45/100 = 45.0% | **−12.0pp** | **[−22.0, −3.0]** | 19 / 7 | **0.029** |

n=100 的检出下限是 4–5pp（配对自举区间不含 0 需 4 条、McNemar 精确检验需 5 条，且没有涨来抵消）：4–5pp 以上的掉幅会被看见。IFEval 净掉 12 条，是下限的两倍多，所以区间整个在 0 的负侧；GSM8K 净涨 3 条，两条判据都没过，所以只能写「没测到」，不能写「没掉」。两格基座分数都还没贴顶到不能用的程度（GSM8K 73.0% [63.6%, 80.7%]，点估计在带上沿之外、判别力偏弱；IFEval 57.0% [47.2%, 66.3%]，落在 30–70% 带正中，与 n=20 时同判）。

IFEval 的 19 条掉点逐条读到指令层（`per_instruction` 就在落盘记录里）：6 条丢「至少/少于 N 词」、4 条丢「不许用逗号」、2 条丢高亮段、2 条丢占位符、2 条丢首尾引号，其余三条各一。机制是同一个：adapter 的回答更短（100 条里 65 条比 base 短，词数中位数 212.5 → 169.0），逗号更多，所以先坏的是表层格式合规，而不是答对答错——两套件 200 份记录 `unscorable` 都是 0。这与 §4.3「提升的 65.3% 是交互项」同一个方向：SFT 改的是回答方式，「按格式写」的能力是这种改动的代价。同一样本前 20 条的读数（GSM8K −10.0pp、IFEval −20.0pp，区间都跨 0）作为前一次估计留在 [`report/sft-benchmark.md`](../../report/sft-benchmark.md)「前一次估计」。

### 4.8 代价

全部 DeepSeek API 调用 9059 次、约 ¥15.65（17 个批次的分项与含/不含口径见 [`report/measurements.md`](../../report/measurements.md)「花费」）；训练一次约 14 分钟 4090；本机测量生成 1452 条回答；benchmark 四格 n=100（400 条回答）跑在单卡 4090 上，墙钟 78.5 分钟、不花 API 钱（另 n=20 的 80 条是前一次估计）。

## 5 限制

1. **一处数据、一个模型、一份法。** 2B、单模型、单一份个人操作法；不外推到 7B 或前沿模型，也不主张这份法比别的法好（[`docs/method/limits.md`](../method/limits.md)）。
2. **样本量小。** 288 条训练样本、151 条处境只有一种决策、验证集 10 个会话组 78 条；benchmark n=100（GSM8K 200 条、IFEval 295 条的全量未跑），且四格各是一次抽样、单 seed、贪心解码，两个套件各检验一次而没有做多重比较校正——IFEval 的 p=0.029 在 Bonferroni α=0.025 下不过线，所以它是「未校正显著」，不是「稳健显著」。
3. **口径一的前提是错的读法。** 主指标以「回答里先出现可解析工具行」为前提，而 base 侧这个前提只有 5.6%，所以 base 贴 0，0 里混着「不会写」与「写了不对」。三个口径并列就是为了拆这层。
4. **参照物不是判据。** 一致率是「像不像带法 DeepSeek」，不是「做得对不对」；参照物可用性只覆盖 148/242，94 条处境没有任何一致率数字，方向未知。
5. **口径二只能否证。** 64.5% 的参照物是单一特征签名，在这些处境上「一致」只意味着两侧都只给了可核对产物。
6. **尺子分得开两端，但两端都低**（§4.6）：同协议下带法 0.3198、不带法 0.2605，差 0.0593 不含 0，所以「读了法」与「没读法」是分得开的；但参照物对自己只有 0.32，差值量级只有约 6 个百分点，所以本文任何「适配器离带法还差多少」的表述都只在「离一个具体参照物多远」的意义上成立，不读作法条效果的百分比。
7. **窄版 LoRA 只覆盖部分层**：18 层线性注意力的投影没挂 LoRA，是选择而不是缺口（宽版更差），但这限制「LoRA 能改到多少」的可比性。
8. **温度 0 下服务端仍不确定**：同提示重发有 42–51% 的动作差异，这批数据的噪声地板就在这里；本地侧 30 条回答与锚点 11 条被 max_new_tokens 截断，按原样进统计，压制幅度未测。
9. **法的适用是推断**：法的覆盖范围由它的角色定义决定，本研究对法的读法不是法条授权。

## 6 结论

把这份操作法压进 2B 权重，能做到的是**换回答方式**：模型开始写工具行（5.6% → 75.2%），动作一致率从 0.0023 升到 0.0968（Δ = 0.0946 [0.0586, 0.1351]，n = 148 处境）。这次提升的 65.3% 是交互项、5.3% 是决策项的独立份额（区间跨 0），文字层口径不支持「决策变像了」（Δ = −0.0473 [−0.1085, 0.0118]）。通用能力侧不是平的：GSM8K 没测到下降（+3.0pp [−6.0, +12.0]，n=100），**IFEval 测到 −12.0pp [−22.0, −3.0]**，掉点逐条读下来是回答变短、逗号变多这类表层格式合规的代价（§4.7）。更根本的是：同协议下参照物自身只有 0.3198 的自洽度，带法与不带法之差 0.0593 [0.0263, 0.0923] 不含 0——这把尺分得开「读了法」与「没读法」，但只能读成「离这个具体参照物多远」，读不出「补上了几成法条效果」。

一句话的结论：**SFT 学会了工具行这个格式，代价是另一层格式（指令合规）掉 12 点；决策没有学会；而这个仪器还没有敏感到能判定决策有没有动。**
