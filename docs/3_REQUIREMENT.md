## CONFIRMED

### 功能

1. **交付物是一份可加载的适配器**：基座 `Qwen/Qwen3.5-2B` + LoRA 权重，加载方式与 sha256 登记在 `artifacts.tsv`
   （权重不进 git，`.tmp/` 是可删临时区）。
2. **政策轴必须自建尺子并先证明它有刻度**：同一批处境、同一套解码下，带法减不带法的差要能排除 0。
3. **通用能力至少两条轴**，且每条先测 headroom：base 落在 30–70% 才留。
4. **每个结论都能从仓库里的落盘证据重算**，不需要重跑模型。
5. **参考实现复核**：至少一条轴用 Google 官方 grader 重算同一批输出，确认结论不是自己那把尺子的产物。
6. **主张面有可执行检查**：`scripts/check_axes_claim.py` 在含糊措辞或越界声称时非零退出。

### 非功能

- **确定性**：训练 seed 0；生成按 draw 定种子；判分是贪心；官方 grader 必须钉 `DetectorFactory.seed = 0`
  与 `random.seed(0)`，否则 `change_case` 检查器自己不可复现（同一份输出两次运行给 160 与 159）。
- **可离线**：除 DeepSeek 锚点批与 HF/Google 的一次性取回外，重算全在本机；`--analyse` 不联网、不碰 GPU。
- **纯 CPU 重算是秒级**：`python3 scripts/measure_actions.py --analyse` 实测 3.17–3.33 s（9 次计时，Python 3.12.3、
  12 核、只用标准库、含解释器启动）。机器被别的作业压满时本轮没量过，所以只给实测区间、不给上界。
- **prompt 不含法条原文**：生成前置断言（175 条法条短语 × 242 条 prompt），命中即停；这是整个实验的成立条件。
- **两侧上限必须一致**：要与落盘侧配对的新生成，沿用落盘侧的上限（320），不换成新的 3110。

### 约束

- 单一用户、单一份法（264 叶子）、单一模型尺寸（2.21 B）、单卡 4090；法变了结论不自动成立。
- 训练样本 288 条、验证 78 条，测于 242 条处境；覆盖 175 条可训练规则里的 77 条（下界）。
- 政策一致率只在 148/242 条处境上算（94 条参照物定不下来），不能外推全域。
- 窄版 LoRA 只挂 `q/k/v/o`（6 层全注意力）与 MLP（24 层），18 层线性注意力的投影没挂——宽版重跑更差，是选择不是缺口。
- 落盘的回答里有 30 条（本地 1452 条中）在 320 处截断、锚点 42 条（2664 条中，1.6%）触顶 320：方向是低估，压制幅度未测。
- 许可：本仓库代码与文档 `AGPL-3.0-only`；适配器是基座衍生权重，随基座走 Apache-2.0（原文见 `README.md`「许可」与 `THIRD-PARTY.md`）。

## INFERRED

  n=295 过线之后，那条敏感性降级为「只属于 n=100」。

  证据指针在 `9_IMPLEMENTATION.md`，仓库布局也在那里。
