# 探针 5：0.594 里有多少是生成抽样噪声

类型：结果（探针）。所有者：主代理。上游：[实验规格](../method/spec.md) §6 门 1，[预注册](../method/prereg.md) §1、§2，[探针 4](probe-4.md)（full vs bare 0.594，slice vs bare 0.590，但每条件只生成一次），[探针 3](probe-3.md)（同一批处境的点估计 0.389）。

状态：**完成**。0.594 在多抽样下没有存活（0.5629，Wilson 与聚类区间都含 0.5）。同条件对照显示评委有很强的 Y 位偏好（0.913），按预注册配对 share 报为有偏；位置分层显示两个探针的 share 都由一个很强的 Y 位偏差主导；两次重判的评委方差接近零（20/20），所以探针 3 与探针 4 的分歧不能归给评委，而来自映射差异与答案差异。数字见 §4。探针 6 把同一批配对按两个位置各判一次，确认 0.5629 不能作为效应量：一致对 34 / 46 = 0.7391（聚类 [0.5556, 0.8889]），位置平衡合并 0.5714（聚类 [0.5197, 0.6273]），但不一致率 0.7246 超过预注册的 0.5，见 §4.9。

复算命令：`python3 report/probe-5/analyse.py`，从 `report/probe-4/situations.jsonl`、`report/probe-3/`、`report/probe-2/judge/` 与 `report/probe-5/` 的产物重算本文每个数字，不等即退出非 0。

## 1 问题

探针 4 在 183 条处境、51 个会话上测得 `full vs bare` = 0.594（180 个非 tie，Wilson [0.5215, 0.6635]，会话聚类 bootstrap [0.5030, 0.6766]），`slice vs bare` = 0.590。但同时发现：同一段摘录、同一句指令、temperature 0，探针 2 存下的答案只有 1/17（full）与 2/17（bare）被逐字复现。temperature 0 在这个端点上不是确定性的生成。

于是 0.594 是**一次生成抽样上的点估计**，不是分布的期望。它与探针 3 的 0.389 方向相反，最可能的原因是两者的抽样不同，但探针 4 没有逐条重判旧答案，所以“生成方差”与“评委方差”没有分开。

本探针按代价从低到高分三步：

1. **评委方差**：把探针 2 的 20 对已存答案用探针 4 的评委重判两次。答案固定，只有评委抽样在变。
2. **抽取噪声**：60 条处境，每个条件生成 3 次，得到 180 个配对比较，让“同一处境换一次抽样还赢不赢”可测。
3. **同条件对照**：每个处境再加一对 `full_1 vs full_2`。两边条件相同，行为良好的评委没有理由偏好任一边；任何方向的偏好都是要报的偏差。

## 2 预注册（任何生成或评委调用之前写入，之后不改）

**样本**。从 `report/probe-4/situations.jsonl` 的 183 条处境中取 60 条，按信号分层：S1 20、S2 5、S3 8、S4 22、S5 5，合计 60；每个会话最多 2 条；选择种子 `20261027`，稀缺信号先选。**n 固定为 60，不因结果再加处境。**

**生成**。每个处境、每个条件（`bare`、`full`）生成 k = 3 次，共 60 × 2 × 3 = 360 次。temperature 0.0（逐次记录在 `calls.jsonl`），thinking disabled，`max_tokens 600`，续写指令与探针 4 逐字相同；`bare` 无 system message，`full` 是 `/home/vibe/AGENTS.md` 的整字节。

**评委**。每条判断用探针 4 的评委 prompt 与设置：system 为 AGENTS.md 全文，temperature 0.0，thinking disabled，`max_tokens 500`，`response_format: json_object`。每个处境判 4 次：

- 3 个配对比较 `full_i vs bare_i`，i = 1..3；
- 1 个同条件对照 `full_1 vs full_2`。

X/Y 顺序由记录下来的种子逐比较掷币：配对用 `20261030`，对照用 `20261031`；映射只写在 `map.json`，请求里不出现 `bare` / `full` / 条件标签。`clause` 只做逐字检查并记录，不重问——本探针不使用 clause。

**主统计量**。

- `paired share` = full 胜 / (full 胜 + bare 胜)，覆盖全部 180 个配对比较；逐字节相同（`identical`）与 tie 不进分母、单列报告；另报以 180 为分母的全体 share。
- Wilson score 95%（z = 1.96）与会话聚类 bootstrap 95%（重抽 38 个会话，10000 次，种子 `20261029`）都报，判定要求两个区间方向一致。
- `control share` = X 胜 / (X 胜 + Y 胜)，覆盖 60 个同条件对照；同样的 Wilson 与聚类 bootstrap。两边条件相同，期望 0.5。
- **逐处境离散度**：每个处境在 3 次配对里 full 胜的次数，报 3/3、2/3、1/3、0/3 的处境数；把非全胜（在决定的比较中 0 < full 胜 < 决定数）的处境记为“在抽样间翻转”。

**判定**。

- **偏差判定**：同条件对照的区间包含 0.5 → 未检出位置/篇幅偏差，配对 share 按原样报；不包含 0.5 → 配对 share 必须报为有偏，并写出偏差方向与大小（对照 share 距 0.5 的距离，以及按 full 在 X 或 Y 拆开的配对 share）。
- **“真实但小”**：只有在 180 比较的区间（Wilson 下界 > 0.5 且聚类 bootstrap 下界 > 0.5）排除 0.5、且对照区间包含 0.5 时才成立。
- 若配对区间包含 0.5 → **探针 4 的 0.594 在多抽样下不成立**，按此写。
- 报告新 share 相对探针 4 的 0.5944 移动多少，以及 0.5944 是否落在新区间内。
- 不跑更多处境来救结果；不再改口径。

**评委方差（描述性，不设门）**：探针 2 的 20 对答案重判两次，报两次之间的 winner 一致率；各自与探针 3 存下的原判一致率；以及各自与探针 2 四项 rubric 的臂偏好（rubric 总分较高的一臂，打平不计）的一致率。

## 3 方法

**评委方差的请求与探针 3 逐字节相同**：同一摘录、同一对已存答案、`report/probe-3/map.json` 的同一 X/Y 顺序、同一 system message。`analyse.py` 用探针 3 `calls.jsonl` 的 `request_sha256` 复核这一点。因此两次 pass 的差异只来自评委抽样。

**60 条处境的抽取**（`build.py`，`analyse.py` 复算）：探针 4 的 183 条按信号分组；每个信号内按处境编号排序，用一个 `20261027` 的 RNG 依次洗每个信号的池子；按 S2、S5、S3、S1、S4（稀缺优先）依次取到分配数，跳过已有 2 条的会话。

**调用与记账**：所有 API 调用（生成、评委方差、配对、对照）逐行写 `calls.jsonl`，含 model、temperature、thinking、`created`、usage、成本与 system/request sha256。`answers.jsonl` 存生成答案与 `call_id`，`judge-out.jsonl` 存判读与 `call_id`，`judge-variance.jsonl` 存两 pass 的判读。

**预算**：¥8。先跑冒烟（2 个处境的生成；2 次评委方差；3 次配对/对照判断），打印实测 usage 与花费，投影剩余；投影超 ¥8 即停。

## 4 结果

### 4.1 评委方差：两次重判几乎完全一致

探针 2 的 20 对已存答案，用与探针 3 逐字节相同的请求重判两次：

| 比较 | 一致 |
|---|---|
| pass 1 vs pass 2 | **20 / 20** |
| pass 1 vs 探针 3 原判 | 19 / 20 |
| pass 2 vs 探针 3 原判 | 19 / 20 |

唯一的分歧是 SIT14：两次新判都是 `Y`，探针 3 存下的是 `tie`。把 winner 按探针 3 的 `map.json` 映射回臂后，两次 pass 都是 law 7 / bare 12 / tie 1（law share 0.368），与探针 3 的 7 / 11 / 2（0.389）只差这一个 tie。**评委方差接近零**：同一批答案、同一个 X/Y 顺序，重判不会把探针 3 的低 share 变成探针 4 的 0.594。

探针 2 的四项 rubric 只在 4 个处境上有严格偏好（SIT02、SIT19 偏 law，SIT07、SIT13 偏 bare）。两次重判在这 4 对上与 rubric 偏好 **4 / 4** 一致；其余 16 对 rubric 打平，不能提供方向。

### 4.2 主结果：180 个配对比较

360 条生成（60 处境 × 2 条件 × 3 抽样）全部成功、无空答。

| 项 | 值 |
|---|---|
| 配对比较 | 180 |
| full 胜 | 94 |
| bare 胜 | 73 |
| tie | 10 |
| 逐字节相同（forced choice 无定义） | 3 |
| 非 tie 分母 | 167 |
| **paired share** | **0.5629** |
| Wilson 95% | [0.4871, 0.6359] |
| 会话聚类 bootstrap 95%（38 会话，10000 次） | [0.4857, 0.6404] |
| 全体 share（分母 180） | 0.5222 |

**两个区间都包含 0.5。** 点估计相对探针 4 的 0.5944 移动 **−0.0315**；0.5944 本身落在新区间内，所以旧点值不与新数据矛盾，但“效应排除 0.5”这个结论**不成立**。按 §2 的预注册规则，0.594 在多抽样下没有存活。

### 4.3 同条件对照：评委有很强的 Y 位偏好

每个处境判一对 `full_1 vs full_2`，两边条件相同：

| 项 | 值 |
|---|---|
| 对照比较 | 60 |
| judge 选 X | 4 |
| judge 选 Y | 42 |
| tie | 1 |
| 逐字节相同 | 13 |
| 非 tie 分母 | 46 |
| **X share** | **0.0870** |
| X Wilson 95% | [0.0343, 0.2032]；聚类 bootstrap [0.0204, 0.1739] |
| **Y share** | **0.9130** |
| Y Wilson 95% | [0.7968, 0.9657]；聚类 bootstrap [0.8261, 0.9796] |

区间远离 0.5。按 §2，配对 share 必须报为**有偏**：偏差方向是 **Y 位**，大小是 46 个决定对照里 42 个选 Y（0.913，机会水平 0.5）。这不是篇幅偏差：47 个被判对照里，X 侧平均 389.1 字符、Y 侧 383.9 字符，Y 侧并不更长。

### 4.4 位置分层：0.5629 是两种近乎相反的结果的平均

| full 的位置 | full 胜 | bare 胜 | tie | identical | share |
|---|---|---|---|---|---|
| full 在 **Y** | 71 | 11 | 6 | 0 | **0.8659** |
| full 在 **X** | 23 | 62 | 4 | 3 | **0.2706** |

同一个评委，同一批答案，只因为法臂落在 Y 还是 X，share 从 0.27 跳到 0.87。总 share 0.5629 是这两个数的混合，不是一条稳定偏好。这个分层是在看到结果之后做的（§4.6 用它重读探针 3 与探针 4），不改变 §2 的判定。

若把位置偏差建模为常量、法臂的内容优势为 δ，则 δ = (q + r − 1) / 2（q 为法臂在 Y 时的胜率，r 为在 X 时的胜率）：本探针 δ = **0.0682**，位置分层区间 [0.0083, 0.1281]。这只是事后敏感性读数，不是预注册统计量。

### 4.5 逐处境离散度：多数处境换一次抽样就翻转

| 3 次配对里 full 胜的次数 | 处境数 |
|---|---|
| 3 / 3 | 9 |
| 2 / 3 | 19 |
| 1 / 3 | 22 |
| 0 / 3 | 1 |
| 2 / 2 | 3 |
| 1 / 2 | 1 |
| 0 / 2 | 2 |
| 0 / 1 | 2 |
| 0 / 0（全 tie 或 identical） | 1 |

51 个处境三次都 decisive，其中 **41 个不是全胜**（9 个 3/3、1 个 0/3），即 **80.4%** 的处境在三次抽样间翻转。60 个处境整体看，**42 个（70.0%）**至少在两次抽样之间改变胜负。抽样噪声在处境层面很大：单一处境的一次生成不能代表它的“真值”。

### 4.6 探针 3 与探针 4 的分歧：位置偏差，不只是生成方差

用同一份已存判读按“法臂在 X 还是 Y”重切探针 4 与探针 3，不需要新调用：

| 探针 / 比较 | 法臂在 X | 法臂在 Y | 合计 share |
|---|---|---|---|
| 探针 4 `full vs bare` | 22 / 88 = 0.2500 | 85 / 92 = 0.9239 | 0.5944 |
| 探针 4 `slice vs bare` | 26 / 90 = 0.2889 | 76 / 83 = 0.9157 | 0.5896 |
| 探针 3 `law vs bare` | 2 / 11 = 0.1818 | 5 / 7 = 0.7143 | 0.3889 |

三个探针里位置分层都呈同一个形状：法臂在 Y 时 share 约 0.71–0.92，在 X 时约 0.18–0.29。探针 3 的法臂有 8/20 落在 Y、12/20 落在 X，探针 4 接近一半一半（full 在 Y 92/180）。按各自的位置权重，这两组条件胜率分别预期 0.395（探针 3）与 0.594（探针 4），与实测的 0.389 和 0.594 几乎相同。**4.1 已排除评委方差**，所以分歧不是评委噪声：其中约 0.07 来自两个探针随机映射的位置配比不同，其余来自两批答案本身的条件胜率不同（探针 3 的 0.18/0.71 对探针 4 的 0.25/0.92），也就是生成抽样差异。

按 `full_vs_bare` 的位置分层做同一个 δ 读数：探针 4 full +0.0870（区间 [0.0342, 0.1397]），slice +0.1023（[0.0467, 0.1578]），探针 3 −0.0519（[−0.2544, 0.1505]），探针 5 +0.0682（[0.0083, 0.1281]）。事后看，除样本只有 20 的探针 3 外，其余都指向一个约 +0.07 到 +0.10 的小内容效应；但这是位置分层模型下的读数，不是预注册检验，且评委的位置偏差已达到 0.913，这个仪器不能单独支撑“法被偏好”的结论。

### 4.7 判定（按 §2 机械读）

- 180 比较的区间（Wilson 与聚类 bootstrap）都包含 0.5 → **探针 4 的 0.594 在多抽样下不成立**；点估计移到 0.5629，移动 −0.0315。
- 同条件对照的区间不包含 0.5 → 配对 share **必须报为有偏**，方向为 Y 位，大小为 0.9130 对 0.5。
- “真实但小”要求配对区间排除 0.5 **且**对照区间包含 0.5；两条都不满足，因此**不能**如此声称。

更强的结论不在预注册判定里，但数据说得很清楚：这个强制选择仪器的读数由 Y 位偏差主导，探针 4 的 0.594 不是可以单独读成“法偏好”的量；探针 3 的 0.389 同理。门 1 的仪器需要一个位置对照，或用同处境双向各判一次并要求方向一致，否则它的 share 不能进入论文的主表。

### 4.9 位置混同的定案（探针 6）：0.5629 不是效应量

§4.2 的 0.5629 是位置混同的读数，不是“法被偏好”的量。探针 6 用同一评委、同一问句把本探针的 240 对（180 个配对 + 60 个同条件对照）按两个位置各判一次，只让两个次序指向同一臂的配对进 share：

| 项 | 值 |
|---|---|
| 一致对里的法胜 share | 34 / 46 = **0.7391**，Wilson [0.5974, 0.8440]，会话聚类 [0.5556, 0.8889] |
| 不一致率 | **0.7246**，Wilson [0.6523, 0.7867]，聚类 [0.5774, 0.7610] |
| 两序合并（位置平衡）share | 196 / 343 = 0.5714，聚类 [0.5197, 0.6273] |
| 对调后的同条件对照不一致率 | 34 / 45 = 0.7556，Wilson [0.6133, 0.8576] |
| 对调后对照的一致侧 share | 5 / 11 = 0.4545，Wilson [0.2127, 0.7199] |

读法：位置偏好被对调变成了同一对答案的自相矛盾（对照 0.7556），所以位置不再直接进入 share；但可判定的配对只剩 46 个（四分之一），且探针 6 的预注册要求不一致率低于 0.5，单此一条就没达到，所以**本探针的 0.5629 既不成立也不被替换成一个新的效应量**。位置平衡合并的 0.5714 指向一个约 7 个百分点的小法偏好，它也是本探针 0.5629 的位置平衡版本，但它是探针 6 的次要数字，不构成判定。

## 6 限制

- **同条件对照本身只判一次。** 60 个对照里 13 个逐字节相同、1 个 tie，46 个决定；Y 偏好 0.913 的区间仍然很窄，但对照没有重复抽样，不能区分“Y 位偏好”与“第二次展示的答案更容易被读成更完整”。长度读数（X 389.1 / Y 383.9 字符）排除了篇幅解释。
- **位置分层与 δ 读数是事后的**，不在预注册里；预注册的主判定只用 §4.2 的未分层区间与 §4.3 的对照区间。分层读数用于解释，不改判定。
- **聚类 bootstrap 不覆盖映射方差。** 会话重抽保持每个处境的 X/Y 位置不变，因此它度量的是会话间差异，不是随机映射带来的方差；4.6 的分层才是后者的直接证据。探针 4 的 Wilson/聚类区间也有同样的问题，它把 180 对当成独立 Bernoulli，在位置偏差下过窄。
- **k = 3 很小**，逐处境的 3/3、2/3、1/3、0/3 只能粗略描述离散度；42/60 的翻转率是最稳健的读法。
- **抽样池仍是探针 4 的 183 条、38 个会话**，且 S6 仍然缺席（探针 4 的候选池里 S6 没有合规窗口）；结论不能外推到“所有处境”。
- **评委与受试同家族**（`deepseek-flash`），跨家族复核仍未做；而且这次的问题不是家族相似，而是位置偏差，跨家族复核未必修得掉。
- **生成调用 372 次，答案只用 360 次。** 冒烟阶段的 12 次生成在第一版 runner 里没有落进 `answers.jsonl`，因此主循环又生成了同样的 12 个（处境、条件、抽样）组合；`answers.jsonl` 按每个组合取最早一次调用重建，后 12 次仍留在 `calls.jsonl` 并计入花费。差额 $0.003，不影响任何统计量。
- **`clause` 未重问**：本探针不使用 clause，逐字率（判读 84.4%）只作仪器质量读数。
