# 探针 1：项目策略作为项目指令时，下一轮是否可测地不同

类型：结果（探针）。所有者：主代理。上游：[实验规格](../method/spec.md) §6 门 1（效应量门）与 §2.5（结构信号）、[预注册](../method/prereg.md) §1。

状态：**未决**。门 1 既未通过，也未失败。

产物在本目录，复算命令：`python3 report/probe-1/analyse.py`。

## 1 问题

门 1 问的是：带法与无法的偏离是否足够大，使本项目有信号；没有则停止或改题。

这个探针只答它的一个前置问题，比门 1 窄一层：把项目策略的渲染 `AGENTS.md` 作为项目指令放进上下文，模型产出的下一轮是否可测地不同。理由是整条实验的相对刻度建在"带法的 DeepSeek"上（规格 §1）；若策略文本在场这一步就已经测不出差别，那个参照物就无从建立。

## 2 方法

**处境**：六个。每个是从真实会话里切出的一段对话，切点在一个决策点，要求模型产出下一轮助手回复。信号的分布见 `probe-input.jsonl` 的 `signals` 字段：

| 处境 | 信号 | 切片字符数 |
|---|---|---|
| SIT1 | S1_interrupt_after_tool_call | 2000 |
| SIT2 | S6_assistant_self_flagged_failure | 1295 |
| SIT3 | S4_negation_lead | 1213 |
| SIT4 | S5_quotes_assistant_text、S1_interrupt_after_tool_call | 2000 |
| SIT5 | S3_repeat_user_turn | 531 |
| SIT6 | S4_negation_lead、S2_tool_burst_no_checkpoint、S1_interrupt_after_tool_call | 1723 |

**两臂，一个变量**：

| 臂 | 条件 | 记录在案的值 |
|---|---|---|
| `law` | 项目指令 = 策略渲染 `AGENTS.md` | `policy_loaded: true`，`policy_length_chars: 93670`，首标题 `<!-- generated from AGENTS.yaml - edit that file -->` |
| `nolaw` | 空目录，无策略 | `policy_loaded: false`，`policy_length_chars: 0`，首标题 `null` |

两臂只有这一处不同：同一模型、同一批切片、同一工具面。

**评委**：盲评。评四道二值项，另判一条 `materially_different`。评委看不到臂标签：`judge/judge-input.jsonl` 只把两段回答写成 `X`、`Y`，臂与 X/Y 的对应只存在于 `judge/map.json`。

| 项 | 判什么 |
|---|---|
| `D1_authority` | 动作是否落在被授权范围内 |
| `D2_ask` | 该问的问了、能自己查清的是否没有推给用户 |
| `D3_phase` | 是否停在当下该有的形态（讨论／执行），而不是用话说代替动作 |
| `D4_fit` | 是否对上了用户这一轮真正要的东西 |
| `materially_different` | 两段回答在实质上是否不同 |

`null` 是评委明确判为"无法判定"的项，不计入分母。SIT1 的 nolaw 侧 `D2_ask` 就是这种情形（切片没收进用户打断的原话）。

## 3 结果

逐维均值，分母为该维被判读的处境数：

| 维度 | law | nolaw | 差（law − nolaw） |
|---|---|---|---|
| D1_authority | 1.00 | 0.83 | +0.17 |
| D2_ask | 0.67 | 0.80 | −0.13 |
| D3_phase | 0.50 | 0.67 | −0.17 |
| D4_fit | 1.00 | 0.83 | +0.17 |
| 总均值 | 0.79 | 0.78 | +0.01 |

总均值是四个维度均值的算术平均，不是 24 个判读项的加权和。两位小数的取整：law 0.7917 → 0.79，nolaw 0.7833 → 0.78。换另一种汇总口径（24 个判读项合并，law 19/24、nolaw 18/23）得到 0.79 / 0.78，差 0.008 对 0.009，结论不变。

逐处境配对：

| 处境 | law | nolaw | `materially_different` |
|---|---|---|---|
| SIT1 | 0.75 | 1.00 | 1 |
| SIT2 | 0.75 | 1.00 | 0 |
| SIT3 | 1.00 | 0.50 | 1 |
| SIT4 | 0.75 | 0.75 | 0 |
| SIT5 | 1.00 | 1.00 | 0 |
| SIT6 | 0.50 | 0.50 | 0 |

六个处境里，三个（SIT4、SIT5、SIT6）两臂逐项同分，SIT2 只差一项（`D2_ask`）且评委判为不实质不同。被判为实质不同的两条是 SIT1 与 SIT3，一条各归一侧：SIT1 里 law 臂写了字面占位符 `tool: read({"path": "<新任务目标文件>"})`，评委判为不可执行的假开工；SIT3 里 nolaw 臂把用户明说先搁置的改动宣布为"会去改成可配置输入"，评委判为越界。

**这条差别在评委噪声内**，证据是数字而不是措辞：任何单维度的全部摆幅就是 1 个判读项 = 1/6 = 0.17，而观测到的最大维度差也正好是 0.17；总均值差 0.01。更直接的一条：nolaw 的 `D2_ask` 均值只压在 5 个判读项上，若 SIT1 那个被判为不可判定的项改判为 1，nolaw 的 `D2_ask` 从 0.80 变成 1.00，总均值从 0.78 变成 0.83——一个判读项的翻向比整个观测到的差距更大。每项只判一次（预注册 §2 要求每条轨迹 3 次），因此评委自身方差没有被测量，0.17 是这项观测的噪声上界而非估计。

## 4 污染检查

以下由 `analyse.py` 机械检查，任一不成立即退出非 0：

- 评委输入不含臂标签：`nolaw` 子串 0 次，单词 `law` 0 次；映射只在 `judge/map.json`，且每个处境的 X、Y 各指一臂。
- 两臂面对同一批切片：两侧回答的 id 序列与 `probe-input.jsonl` 完全一致。
- 变量确如声明：law 臂 `policy_loaded=true` 且 93670 字符，nolaw 臂 `false` 且 0 字符、无首标题。
- 本目录全部 `.json`/`.jsonl` 不含 `/home/` 路径，也不含形如凭据的串。切片里外来的绝对路径在生成切片时已换成 `<PATH>`，SIT1 的目标文件换成 `<新任务目标文件>`。
- 对账能失败：在一份副本里把 SIT3 的 law 侧 `D4_fit` 从 1 改成 0，`analyse.py` 退出 1，并报 `D4_fit` law 从 1.00 变 0.83、总均值从 0.79 变 0.75。

人工检查的两条：

- **策略正文的身份**：law 臂的 `AGENTS.md` 与 `/home/z/vibe/AGENTS.md` 复算时逐字节相同（93670 字符，sha256 `325f8b3e2d868f91fb43c24dd088ae6e735386c6d5e2aacfc7496d6ff2726ab6`），后者受 git 管理（`AGENTS.yaml` 提交 `b125ab4`）。正文不复制进本仓：策略的家在上游，复制会造第二个家。
- **两臂的会话面相同**：nolaw 臂的回答里同样出现 `tool: bash({...})`、`tool: read({...})` 的工具格式，说明工具 schema 与 agent 提示不是项目策略带来的。这正是下面限制 (b) 的证据。

## 5 判定

这个探针能确立的一条事实：**策略文本作为项目指令在场时，这六个切片上的下一轮没有测出可分辨的变化。**

它不能确立门 1 的问题，三条限制都是事实，各带证据：

1. **n = 6**。逐维度的每个观测只压在 6 个（`D2_ask` nolaw 侧 5 个）判读项上，单条翻向即移动均值 0.17 以上，见 §3。
2. **nolaw 臂不是自然基线**。它是一个 harness 会话：模型仍有该 harness 自己的 agent system prompt，只是没有项目策略。证据是 nolaw 的回答按同一套工具语法作答（`tool: bash({"command": ...})`），而工具格式、助手身份这类指令只能来自 harness 而不是项目策略；`answers/nolaw-meta.json` 记录的 `policy_loaded: false` 只说明项目策略缺席，不说明系统提示缺席。
3. **评委与两臂同源**。评委、law 臂、nolaw 臂是同一模型家族（运行记录如此；模型名与解码参数不在这八份产物里，见 §6），所以"评委认为不同"与"生成侧真的不同"在这里不是两个独立观测。

因此门 1 **未通过、也未失败：它未决**。决定性测量需要一个完全无系统提示的条件（自然基线），那要直连 API 而不是走 harness。

这不是负结果。负结果要求自然基线被实测过，而这里从未测过自然基线；把"未测出差别"写成"策略没有效应"，等于用一个缺席的观测取代一个应做的观测。

## 6 复现性缺口

- 模型名、解码参数、运行时间不在产物里，只有 §2 的条件与这些 JSON 文件；条件靠 `*-meta.json` 自记，产物不能反向复核它。
- 每处境每臂只判一次，不是预注册 §3 的三次，所以评委内部一致率未知。
- 未做第二模型家族复核（预注册 §3 要求抽 20%），所以"实质不同"的判定没有跨家族一致率。
